# Salesforce Development Notes - Day 1 to Day 69


## Reading order

Follow the files from `Day_01` to `Day_69`. Each file contains: source-aligned concepts, a beginner explanation, multiple examples, comments explaining why each important line exists, common mistakes, an interview answer, and practice. Days 2, 9, 10, 11, and 12 include expanded data-type and collection method catalogs.

## Important numbering note

The source includes extra labels such as **Day 57.01** and **Day 59.1**. Their material has been merged into the nearest numbered lesson so the package remains exactly Day 1 through Day 69: Batch introduction is included in Day 58, and async testing is included in Day 59.
